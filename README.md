# Gorilla WWE 2K26 Mod Manager

A free Windows tool for managing WWE 2K26 PC mods.

## What Gorilla does

- Manages only the CAK mods you explicitly choose.
- Organizes managed mods into Main Game, Clean, Recording, and Mod Test Profiles.
- Switches setups without manual CAK moving.
- Turns individual managed mods ON or OFF.
- Saves and restores a Last Working Profile.
- Uses Mod Doctor to help narrow down problem mods.
- Pauses mod changes while WWE 2K26 is running.
- Keeps unmanaged mods untouched.

Open Gorilla before WWE 2K26, choose or switch your Profile, then play.
